# Kulmis Market

An online shop for handcrafted products, plus a trading-signals service and a
monthly membership with a 3-level referral program. Built for Ethiopia, priced
in ETB.

- Backend: Laravel 13 + MySQL, database queue + cron
- Storefront: server-rendered Blade with a static page cache
- Admin: React (shadcn-admin / shadcn/ui), in `admin/`
- API: REST under `/api/v1`
